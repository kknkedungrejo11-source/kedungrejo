# Sistem Informasi / Website Desa (Proker KKN Undip 2026)

Repositori ini berisi dokumentasi dan tautan unduhan untuk proyek website / sistem informasi desa yang dikembangkan sebagai bagian dari program Kuliah Kerja Nyata (KKN) Universitas Diponegoro (Undip) di wilayah Wonogiri pada tahun 2026.

Dikarenakan ukuran file sistem yang melampaui batas kapasitas unggah repositori, seluruh *source code* (file mentahan) dan *database* telah dikompres dan disimpan dengan aman di Google Drive. 

Pihak kelurahan, perangkat desa, atau pengembang (*programmer*) selanjutnya dapat mengunduh seluruh file secara lengkap melalui tautan di bawah ini:

👉 **[Download File Mentahan Website di Sini](https://drive.google.com/open?id=1EYOQrYQ7R-Sb18Urws003JcagHsChr5H&usp=drive_fs)**

## 📌 Tentang Proyek
Proyek ini diserahkan sepenuhnya kepada pihak kelurahan untuk mendukung digitalisasi pelayanan dan administrasi masyarakat. Sistem ini dirancang agar dapat dikelola, dilanjutkan, atau dirombak sesuai dengan perkembangan kebutuhan desa di masa mendatang tanpa ada ikatan dengan pengembang awal.

## 🛠️ Panduan Singkat Penggunaan (Untuk IT/Programmer Desa)
1. Unduh file arsip dari tautan Google Drive di atas.
2. Ekstrak file tersebut ke dalam komputer atau *server/hosting* desa.
3. Jika sistem menggunakan *database* (misalnya MySQL), lakukan impor file *database* (`.sql`) yang telah disertakan di dalam folder.
4. Sesuaikan pengaturan koneksi *database* (biasanya pada file `.env` atau `config`) dengan *server* yang digunakan.
5. Website siap dijalankan dan dikembangkan lebih lanjut.
